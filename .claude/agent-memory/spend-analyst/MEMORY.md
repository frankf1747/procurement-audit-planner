# spend-analyst memory (method lessons only; never evidence)

- **Spend header row varies per workbook** (2026-10-17). Some sheets have the header on sheet row 1, others on row 2 with a blank row 1. Why: fixed `header=0` misreads. Apply: `header=None`, find the row whose first cell is `Service`, re-read with that header; `row_id` sheet row = header_index + 2 + df index.
- **contracts.csv packed supplier column is named `Supplier [Name|Address|Ref type|Ref Number|Is SME|Is VCSE]`**, not `Supplier` (2026-10-17). Apply: select the column by prefix `Supplier [`.
- **contracts.csv `Published Date` mixes ISO offsets (`+01:00` and `Z`)** (2026-10-17). Apply: `pd.to_datetime(..., format="ISO8601", utc=True)`.
- **Supplier normalisation: strip apostrophes, don't space them** (2026-10-17). Why: `X'S` became `X S` and broke exact matches with notice names. Apply: delete `'` / U+2019 before the A-Z0-9 filter.
- **Trading-name marker also appears as `T/AS`** (2026-10-17). Why: `\bT/A\b` misses it (no word boundary before S). Apply: `\b(T/AS?|T\.A\.|TRADING AS)(?=\s|$).*$`.
- **Spec regexes over-match; log, don't silently change** (2026-10-17). `COUNTY` in the inter-authority regex catches non-public bodies with "County" in the name; `RENT|LEASE` in the premises tag catches equipment rentals and lease cars. Report these as data-quality warnings unless the auditor approves a tighter regex.
- **Thresholds 24999.99 and 25000 are the same boundary in rules.json** (CPR-19 vs App B) and give identical clustering bands; report once with the note (2026-10-17).
- **Lowest competition-triggering threshold (App B row A, one quote) sits below any possible annualised estimate in an over-£500 population**, so the literal high_value tier selects nearly every supplier (2026-10-17). Applied: reported that tier as counts only; headline and off_contract use the lowest threshold whose rule requires a contract notice (CDP/Contracts Finder). **Auditor decision (2026-10-17): confirmed.** Use the lowest threshold whose rule requires a contract notice (App B rows B1/B2, the £25,000 publication tier) as the high_value_suppliers headline tier and the off_contract population; keep the one-quote tier as counts only. No need to ask again; state the decision in the report.
- **Use `(?:...)` groups in `str.contains` regexes** to avoid pandas match-group warnings (2026-10-17).
- **Join row_id lists with "; " (semicolon + space), never a bare space** (2026-10-17). Why: the audit-program builder (build_pack.py) splits `row_ids` on `;` or `,` only; space-joined lists made every grouped sample unresolvable. Apply: `"; ".join(...)` in analyse.py; split with `re.split(r"[;,\s]+", ...)` in selfcheck.
